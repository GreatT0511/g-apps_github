WHY GITHUB

なぜ、学校にGitHubか。

GitHubは「プログラマーの道具」ではありません。ファイルの歴史と、変更の理由が全部残る書類箱です。 学校の3つの困りごとに、そのまま効きます。

history

「最新版どれ?」が消える

プリント_最終_改2.docx とはお別れ。置き場所は1つ、過去の版は履歴から全部たどれて、いつでも戻せます。

luggage

転勤・進級しても消えない

アカウントは個人の資産。先生が異動しても、生徒が卒業しても、積み上げた記録は本人と一緒に移動します。

footprint

思考の過程が財産になる

完成品だけでなく「いつ・何を・なぜ変えたか」が残る。探究の問いの変遷が、後輩に引き継げる景色になります。

info
この講座では GitHub Classroom を使いません。 課題配布に特化した教員向け機能ではなく、世界中で使われている普通のGitHubアカウントを先生自身が使い、そのまま生徒に指南します。 理由は3つ——①卒業後も本人の資産として残る、②社会でそのまま通用するスキルになる、③特別な管理システムがいらない。
