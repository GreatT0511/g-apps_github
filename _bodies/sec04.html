SECTION 04

§4　ハンズオン② Geminiで作った教科サイトをWebに公開する

サイトづくりはGeminiのCanvasに任せ、公開はGitHub Pagesで行います。 プロンプトを貼る → できたHTMLをリポジトリに置く → 公開設定。サーバー契約なし・無料・URLを配るだけです。

使いどころ: 教科の学習ページ・授業リンク集・単元まとめ・部活動や行事の案内。

使う道具: Gemini（Canvas）＋ GitHub Pages（公開リポジトリなら無料）

4-1

公開する前に、これだけは

public
Pagesは「全世界公開」です。無料でPagesを使えるのはPublic（公開）リポジトリ——つまり、ページだけでなくリポジトリの中身と履歴もすべて世界から見えます。生徒の氏名・写真・校内事情は載せない。公開してよいものだけを入れる専用リポジトリを作るのが原則です（下のプロンプトにも「個人情報を入れない」条件が入っています）。
4-2

手順1　GeminiのCanvasでサイトを作る（7分）

  1. gemini.google.com を開き、入力欄の Canvas を選ぶ
  2. 下のプロンプトをコピーして貼り付け、◯◯の部分を自分の教科・学年・単元に書き換えてから送信
  3. 右側にサイトのプレビューが表示されます。直したいところは、そのまま日本語で追加指示（例:「見出しをもっと大きく」「配色を緑系に」）
  4. 仕上がったらコード表示に切り替えて、HTML全体をコピーします
Geminiに貼るプロンプト（◯◯を書き換えて使う） クリックでコピー
あなたはWebデザイナーです。以下の条件で、教科の学習サイトを1ページ作ってください。 【目的】 中学◯年生に配る「◯◯科の授業ページ」。生徒がスマートフォンで開いて、単元の要点と学習リンクを確認するためのサイトです。 【内容】 - サイト名: ◯◯科 学習ページ - 単元セクションを3つ: 「◯◯」「◯◯」「◯◯」。各単元に、要点の箇条書き3行と、学習リンクの箇条書き2つ（リンク先はあとで差し替えるのでダミーでよい） - 「お知らせ」欄を1つ（テスト範囲などを書く場所。今は「ここにお知らせを書きます」でよい） - フッターに「このページは授業用です」と表記 【技術条件（必ず守る）】 - HTMLファイル1つだけで完結させる。CSSは<head>の<style>タグに統合し、外部CSSファイル・外部JavaScript・CDN・画像ファイルは使わない - スマートフォンでも読みやすいレスポンシブデザイン - 配色は教科に合う色を1色だけアクセントに使い、全体は白基調で読みやすく - 文字は大きめの日本語。見出しの階層をはっきりさせる - 学校名・教員名・生徒名などの個人情報や、実在の固有名詞は入れない 完成したら、コード全体を1つのHTMLとして出力してください。
4-3

手順2　GitHubに置いて公開する（5分）

  1. New repository → 名前は kyouka-site（自分の教科名でも可・半角英数）→ 今回は Public → README付きで作成
  2. Add file → Create new file → ファイル名: index.html（この名前だと公開URLの表紙になります）
  3. GeminiからコピーしたHTML全体を貼り付けてコミット → メッセージ: 「教科サイトを登録: Gemini Canvasで作成した初版」
  4. Settings → Pages → Source が Deploy from a branch であることを確認し、Branch を main にして Save
  5. 1〜2分待ってページを再読み込みすると、公開URLが表示されます: https://ユーザー名.github.io/リポジトリ名/
  6. このURLを生徒に配る（Classroomの投稿・QRコード等）
4-4

1つのリポジトリで、サイトを複数持つ

2つ目のサイトを作るたびにリポジトリを増やす必要はありません。ルールは§3-6のフォルダと同じです——フォルダを作って、その中に index.html を置くと、フォルダ名がそのままURLになります。

  • 作り方: Add file → Create new file → ファイル名を sugaku/index.html のように「フォルダ名/index.html」にして、Geminiで作った2つ目のHTMLを貼り付け
  • URLの対応: リポジトリ直下の index.html が表紙 → https://ユーザー名.github.io/リポジトリ名/、sugaku/index.html → …/リポジトリ名/sugaku/、rika/index.html → …/リポジトリ名/rika/。フォルダの数だけサイトを増やせます
  • フォルダ名は半角英数で: URLの一部になるので、日本語ではなく sugaku・rika・bunkasai のようにローマ字で
  • 表紙を目次にする: 直下の index.html に各サイトへのリンクを並べれば、そこが「わたしの教材ポータル」になります。Geminiに「以下のリンクを並べた目次ページを同じデザインで」と頼めば表紙も1分です
  • 公開設定は最初の1回だけ: Pagesの設定はリポジトリ単位です。フォルダを増やしても、設定をやり直す必要はありません
4-5

更新の運用 — Geminiで直して、貼り替えるだけ

  • 更新のたびに履歴が残ります。Geminiで直した新しいHTMLを index.html に貼り替えてコミットするだけ。URLは変わらず、1〜2分で反映。コミットメッセージには理由を——「テスト範囲を更新: 中間試験の範囲発表のため」
  • ダミーのリンクは、GitHub上で index.html を直接編集して差し替えてもOKです（リンク差し替え程度ならGeminiに戻らなくて済みます）
  • 画像を使いたくなったら、リポジトリにアップして相対パスで貼れます——ただし人物が写っているものは載せない
workspace_premium
発展①: 公開できるのはHTMLだけではありません。Markdown（.md）は自動でHTMLに変換されてページになり（README.mdもそのまま公開されます）、PDFや画像はそのままのURLで配信されます——プリントPDFを置いてQRコードで配る運用も可能です。逆にサーバー側の処理（提出受付・ログイン等）は動かないので、アンケートや提出はGoogleフォームへのリンクで併用します。
発展②: プロフィールREADME。ユーザー名と同じ名前のリポジトリ（例: tanaka-sensei/tanaka-sensei）を作ると、そのREADMEが自分のプロフィールページに表示されます。
発展③: 非公開のままWeb公開。Privateリポジトリのまま公開するには有料プランが必要です。まずは「公開専用リポジトリを分ける」運用で十分です。

ワーク — 自分の教科サイトを公開する（12分）

プロンプトの◯◯を自分の教科・単元に書き換えてGeminiに送り、できたHTMLを index.html として公開してください。公開できたら、URLを隣の人とスマホで開き合って確認。「これなら生徒に配れるか?」「個人情報が入っていないか?」の目で相互チェックします。早く終わった人は、4-4の方法で2つ目のサイト（フォルダ）に挑戦。
