図解 画面の見方 — 3つの画面が分かれば迷わない

GitHubで今日使う画面は実質3つ：ホーム（ダッシュボード）・リポジトリの中・設定（Settings）。 それぞれの画面のどこが何をする場所か、番号つきの実画面で確認できます。迷子になったら、このページに戻ってきてください。

画面1

ホーム（ダッシュボード） — ログイン直後の画面

  1. GitHubロゴ／Dashboard — どの画面にいても、ここを押せばこのホームに戻れます。迷ったらまずここ
  2. 検索バー — 自分のリポジトリやファイルを横断検索。キーボードの「/」キーでも開きます
  3. 「＋」ボタン — 新しく作るときの入口。New repository（新しいリポジトリ）はここです
  4. 通知（ベル） — 共同編集者への招待や、プルリクエスト（§6）の連絡がここに届きます。青い点＝未読
  5. 自分のアイコン — アカウント全体のメニュー。Settings（アカウント設定・§1の二段階認証はここから）やサインアウト
  6. Top repositories＋New — よく使うリポジトリへの近道。緑のNewからも新しいリポジトリを作れます
  7. Copilotの質問欄 — GitHubのAIアシスタント。今日の研修では使いません。入力せずスクロールして通過してOK
  8. Feed — 自分のリポジトリやフォローした人の動きが流れる掲示板。見るだけの場所で、操作は不要です
画面2

リポジトリの中 — いちばん長くいる画面

  1. リポジトリ名＋公開状態 — いまどの箱にいるか。Private＝非公開／Public＝全世界公開。作業前にここを一瞥する癖を
  2. タブ列 — 機能の切り替え。今日使うのは Code（ファイル一覧）と Settings（設定）、§6で Pull requests。他のタブは触らなくて大丈夫です
  3. ブランチ（main） — 版の「本流」の名前。この研修では常にmainのまま。変更しません
  4. 緑のCodeボタン／Add file — Add fileがファイルの追加（Create new file／Upload files）、緑のCodeの中にDownload ZIP（丸ごと持ち出し）があります
  5. ファイル一覧 — 行の左がファイル名・フォルダ名、真ん中がそのファイルを最後に変えたときのコミットメッセージ、右がその日時。一覧そのものが「変更理由の一覧」になっています
  6. コミット数（19 Commits） — 履歴（History）の入口。押すとこのリポジトリの全履歴が時系列で見られます（§3で使った画面）
  7. About — リポジトリの説明欄。§4でPages公開すると、公開URLがここに表示されます
  8. README — リポジトリの「表紙」。開いた人が最初に読む説明書で、ファイル一覧の下に自動表示されます（§2で書いたもの）
  9. Deployments／github-pages — Pages公開の状態。緑のチェック＝公開が動いている印です（§4）
画面3

Settings（設定） — 触るのは4か所だけ

  1. General — 基本設定。開いた直後はこのページが表示されています
  2. Collaborators — 共同編集者の招待（§3）。同僚を入れるのはここ。Add people → 相手のユーザー名で招待
  3. Repository name＋Rename — リポジトリ名の変更。URLも変わるので、共有後の変更は慎重に
  4. Pages — Webページ公開のスイッチ（§4）。Branchをmainにして Save するだけ
  5. Default branch — 本流ブランチの設定。mainのまま変えません
  6. Features — Wiki・Issuesなど付属機能のON/OFF。初期設定のままでOKです
warning
Settingsのいちばん下には「Danger Zone」があります。リポジトリの削除・公開範囲の変更など、取り返しに手間がかかる操作のコーナーです。赤い枠が見えたら、それ以上スクロールしない——今日はこれで十分です（万一削除しても90日以内なら復元できます。Q&A参照）。
