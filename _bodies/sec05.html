SECTION 05

§5　実践設計① 生徒の探究を「1人1リポジトリ」で残す

探究の成果物は年度末の発表で消え、問いの変遷は誰にも引き継がれない——ここを変えます。 生徒1人にリポジトリ1つ。READMEが「問いの現在地」、Issueが「問いのログ」、コミットが「選択の記録」になります。

ここまで: §1〜§4で、先生自身が一通り（作る・守る・直す・公開する）を体験しました。この章: それを生徒の探究に載せる設計図を作ります。次: §6で生徒同士のレビューの回し方へ。

使いどころ: 総合的な探究の時間、課題研究、卒業研究、部活動の研究記録。

使う機能: テンプレートリポジトリ＋README＋Issue＋Collaborators

5-1

設計図 — 1人1箱の中身

flag

README = 問いの現在地

いまの問い・考えていること・次の一歩を常に最新に保つ表紙。書き換えるたびに履歴が残るので、問いがどう変わってきたかが後から全部たどれます。

sticky_note_2

Issue = 問いのログ

調べたい疑問が湧いたら1件ずつIssueに。解決したら「わかったこと・出典」を書いて閉じる。閉じた付箋の山が、そのまま探究の足跡になります。

draw

コミット = 選択の記録

AIを使った箇所は「AI案を修正して採用: 理由」と書いてコミット。AIをどう使ったかも、そのまま記録に残ります。

5-2

手順1　先生が「ひな形の箱」を1つ作る

  1. New repository → 名前 tankyu-template → Private → README付きで作成
  2. READMEに下のテンプレを貼ってコミット
  3. Settings → 一般設定の一番上にある Template repository にチェックを入れる
  4. これで生徒は Use this template ボタンから、自分のアカウントに同じ構造の箱を一発で作れます
探究リポジトリのREADMEテンプレ クリックでコピー
# 探究: （仮のテーマ名） ## いまの問い （一文で。変わったら書き換える——変わるのは前進です） ## いま考えていること - ## 次の一歩 - [ ] ## AIの使用記録 AIを使ったときは、コミットメッセージに 「AI案を採用/修正/棄却: 理由」を書くこと。 ## 参考にしたもの - （タイトル・URL・見た日）
5-3

手順2　生徒に配る（授業1コマの流れ）

  1. §1の手順で生徒がアカウントを作る（13歳以上・ユーザー名ルールは§7の配布資料で）
  2. 先生のテンプレリポジトリのURLを配り、Use this template → Create a new repository。名前は「tankyu-2026」等に統一、Privateを選ばせる
  3. 各リポジトリの Settings → Collaborators で先生を招待してもらう——Privateのままでも、招待されたCollaboratorは中を見られます。公開せずに先生と共有できるのがこの仕組みの肝です
  4. 初回のワーク: READMEの「いまの問い」を書いてコミット——これが探究の最初の履歴になります
visibility
公開範囲の原則。探究リポジトリはPrivate＋先生をCollaboratorが基本形。校外に見せたい成果ができたら、そのときに「公開用リポジトリへ移す」を生徒と一緒に判断します（§7のルール参照）。最初からPublicにしない。
groups
おすすめは「探究グループに1リポジトリ」。個人リポジトリ×40人だと、先生は40件の招待を受けて40の箱を巡回することになります。グループ探究なら「1グループ1リポジトリ」にして、先生はグループの箱のCollaboratorになるのがおすすめです——招待はグループ数だけで済み、見取りの巡回先も減ります。グループ内では生徒同士もCollaboratorとして入り、誰が・何を・なぜ変えたかはコミット履歴に個人名で残るので、共同編集でも個人の貢献は見えます（§6のプルリクエスト・レビューにもそのままつながる形です）。個人課題のときだけ1人1リポジトリを使う、という使い分けで十分です。
5-4

運用 — 週1回の「現在地コミット」だけ守る

  • 毎週の探究の時間の最後5分を「READMEを現在地に更新してコミットする時間」に固定する
  • 先生の見取りは、成果物ではなくHistoryを読む——問いの変遷とコミットメッセージの質(「なぜ」が書けているか)が、そのまま評価資料になります
  • 年度末: 発表スライドより先に、自分のHistoryを読み返して「問いはどう変わったか」を語らせる——ふりかえりが自動的に一次資料つきになります
  • 卒業しても箱は本人のもの。後輩に見せたい記録は、学校の「先輩アーカイブ」リポジトリへコピーして引き継ぐ——先輩たちの問いの変遷が、毎年の財産として積み上がっていきます

ワーク — テンプレの箱を作る

自分の担当を想定して、tankyu-template を実際に作り、Template repositoryにチェックを入れるところまで(10分)。READMEの項目は自分の学校の探究の型に合わせて増減してください。
