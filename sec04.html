§4　ハンズオン② 教材ページを5分でWebに公開する

GitHub Pages を使うと、リポジトリに置いたMarkdownがそのままWebページになります。 サーバー契約なし・無料・URLを配るだけ。授業のリンク集、単元のまとめページ、保護者向け案内に使えます。

使いどころ: 授業リンク集・単元まとめ・部活動や行事の案内ページ。

使う機能: GitHub Pages（公開リポジトリなら無料）

4-1

公開する前に、これだけは

public
Pagesは「全世界公開」です。無料でPagesを使えるのはPublic（公開）リポジトリ——つまり、ページだけでなくリポジトリの中身と履歴もすべて世界から見えます。生徒の氏名・写真・校内事情は載せない。公開してよいものだけを入れる専用リポジトリを作るのが原則です。
4-2

手順　リポジトリ作成から公開まで

  1. New repository → 名前は例えば rika-links → 今回は Public → README付きで作成
  2. README.md を開き、下のテンプレを貼って自分の授業用に書き換え、コミット
  3. Settings → Pages を開く
  4. Build and deployment の Source が Deploy from a branch になっていることを確認し、Branch を main にして Save
  5. 1〜2分待ってページを再読み込みすると、上部に公開URLが表示されます: https://ユーザー名.github.io/リポジトリ名/
  6. このURLを生徒に配る（Classroomの投稿・QRコード等）
授業リンク集のテンプレ（README.mdに貼り付け） クリックでコピー
# 理科（中2）授業ページ ## 今週の単元 - 電流と電圧 — [NHK for School の実験動画](https://www.nhk.or.jp/school/) - ふりかえりフォーム — （フォームのURL） ## いつでも使うもの - [教科書会社の資料ページ](https://example.com) - 質問箱 — （フォームのURL） ## 更新履歴 このページの変更履歴は、リポジトリの History からいつでも確認できます。
4-3

運用のコツ

  • 更新はREADMEを直すだけ。コミットすると1〜2分で公開ページに反映されます。URLは変わりません
  • ページを増やしたいときは、リポジトリに 別の.mdファイルを作ればそれも自動でページになります（例: dai1shou.md → /dai1shou）
  • 画像はリポジトリにアップして相対パスで貼れます——ただし人物が写っているものは載せない
  • リンク集の変更もコミットメッセージに理由を書く癖を——「リンク差し替え: 動画が非公開になったため」。次の担当者への引き継ぎ書になります
workspace_premium
発展①: プロフィールREADME。ユーザー名と同じ名前のリポジトリ（例: tanaka-sensei/tanaka-sensei）を作ると、そのREADMEが自分のプロフィールページに表示されます。教員としての実践ポートフォリオの表紙にどうぞ。
発展②: 非公開のままWeb公開。Privateリポジトリを社内限定でPages公開するには有料プランが必要です。まずは「公開専用リポジトリを分ける」運用で十分です。

ワーク — 自分の授業リンク集を公開する

テンプレを使って、担当授業のリンク集を1ページ公開してください（10分）。公開できたら、URLを隣の人とスマホで開き合って確認。「これなら生徒に配れるか?」の目で相互チェックします。
